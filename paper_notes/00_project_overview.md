# Project Overview

## Project
KPA-Tracker reproduction and improvement

## Goal
Reproduce KPA-Tracker, identify its failure modes, and develop a principled improvement for articulated object tracking.

## Current target direction
Robot perception / articulated object tracking.

## Current candidate idea
Uncertainty-aware keypoint tracking, potentially combined with adaptive keyframe update.

## Research philosophy
Do not add modules blindly.
Follow:

Observation
→ Hypothesis
→ Method
→ Evidence

## Current stage
Baseline reproduction completed.
Failure analysis in progress.
